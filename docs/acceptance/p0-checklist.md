# P0 联调验收清单（管理端小程序）

## 1. 环境与账号

- [ ] Django 后端已启动
- [ ] 小程序 `baseUrl` 指向可访问后端
- [ ] 准备管理员账号（可登录 `/api/users/admin/login/`）

## 2. 登录与会话

- [ ] 从 `pages/mine/index` 进入“管理端入口”
- [ ] 输入正确账号密码可登录成功
- [ ] 登录后跳转 `pages-admin/dashboard/index`
- [ ] 清理 `admin_token` 后访问管理页会被引导回登录页

## 3. 控制台

- [ ] `GET /api/users/admin/dashboard/` 返回成功
- [ ] 页面正确显示：今日预约、待审核、用户总数、套餐总数

## 4. 套餐管理（列表）

- [ ] `GET /api/packages/` 返回分页数据
- [ ] 套餐名称、价格、销量、状态显示正确
- [ ] 空数据时显示“暂无套餐数据”

## 5. 预约管理（列表 + 审核）

- [ ] `GET /api/appointments/` 可拉取列表
- [ ] 状态筛选可生效（待审核/已确认/已完成/已取消/已拒绝）
- [ ] 待审核订单可执行“确认”并成功
- [ ] 待审核订单可执行“拒绝”，并传递 `reject_reason`

## 6. 异常处理

- [ ] token 过期时弹出提示并回到登录页
- [ ] 后端返回业务错误时展示 message
- [ ] 网络断开时显示“网络错误”提示

## 7. 结论

- [ ] P0 验收通过
- [ ] P0 验收不通过（记录阻断问题并回归）
