# P1 第五批验收清单（报告录入与用户管理）

> 本清单同时覆盖管理端网页 `admin-web` 与小程序管理页 `pages-admin`。

## 1. 报告录入管理（管理员端）

- [ ] `pages-admin/reports/list` 存在“录入报告”按钮
- [ ] `admin-web/src/views/reports/index.vue` 存在“录入报告”按钮
- [ ] 可录入报告（预约下拉选择、医生、报告日期、摘要、文件URL）
- [ ] 可编辑已录入报告
- [ ] 录入/编辑成功后列表自动刷新
- [ ] 报告列表支持分页切换

## 2. 报告用户可见性（微信端）

- [ ] 管理员录入后，用户端 `pages/report/list` 可看到新报告
- [ ] 用户端可点击“查看报告”预览文件或显示无附件提示

## 3. 用户管理（管理员端）

- [ ] 用户列表页可正常加载与分页
- [ ] 用户列表支持关键词搜索（昵称/姓名/手机号）
- [ ] 用户列表支持状态筛选（正常/禁用）
- [ ] 可执行启用/禁用操作并即时刷新

## 4. 异常处理

- [ ] 报告录入时预约ID为空会提示不可提交
- [ ] 报告编辑取消输入后不会误提交
- [ ] 接口失败不导致页面卡死
- [ ] 管理端分页列表接口报错时有统一错误提示

## 5. 结论

- [ ] P1 第五批验收通过
- [ ] P1 第五批验收不通过（记录问题并回归）
