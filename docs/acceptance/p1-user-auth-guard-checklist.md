# P1 用户端登录守卫联调清单

## 范围

- 用户端私有页面守卫：`预约列表`、`报告列表`、`收藏列表`、`咨询列表/提交`。
- 登录链路：`wx.login -> /api/users/login/ -> token + userInfo + profile_completed`。
- 预约链路：未建档拦截、建档后可自动带入资料创建预约。

## 验收步骤

1. 清空本地缓存（删除 `token`、`userInfo`），直接进入 `pages/appointment/list`。
2. 预期：提示“请先登录”，自动跳转到 `pages/mine/index`。
3. 在“我的”页触发登录，确认缓存写入 `token` 与 `userInfo`。
4. 进入套餐详情点击预约：
   - 若 `profile_completed=false`，应提示先完善资料并跳到资料页；
   - 补全资料后再次进入预约页，姓名/手机号/身份证应自动回填。
5. 提交预约后到“预约列表”可看到新记录。
6. 在“报告列表”直接查看报告：
   - 已有文件时点击“查看报告”可打开预览；
   - 无附件时提示“报告已生成，暂无附件”。
7. 手动伪造失效 token（改写本地 token），访问私有页。
8. 预期：请求返回 401 后清理会话并提示重新登录。
9. 在“我的收藏”点击“取消收藏”，预期当前项立即从列表消失且不跳详情。
10. 从“预约列表”中已完成记录点击“去报告列表”，应能跳转并查看报告列表。
    - 若该预约已出具报告，应高亮定位对应报告项；
    - 若未出具，应提示“该预约报告暂未出具”。
11. 报告列表空状态：显示“暂无已出具体检报告，可先在预约页查看进度”。
12. 在预约创建页校验：
   - 手机号非11位或身份证格式错误时应被前端拦截；
   - 预约日期早于今天时应提示不可提交。
13. 在“在线咨询”列表：
   - 待回复咨询可点击“撤回咨询”并成功移除；
   - 已回复咨询不显示撤回按钮。
14. 在“体检报告”列表中：显示报告医生与摘要信息。
15. 页面提示文案一致性：预约/咨询/报告页面提示文案与常量模块一致。

## 通过标准

- 未登录无法停留在私有页。
- 登录后私有页可正常加载。
- 建档前预约被拦截，建档后可创建预约。
- 预约列表不依赖详情页，已完成记录可直达报告列表。
- 收藏列表支持取消收藏且操作后列表即时更新。
- 报告列表支持直接查看报告文件，无附件有明确提示。
- 预约创建前端校验生效，非法输入不会提交到后端。
- 在线咨询支持用户撤回待回复记录，已回复记录不可撤回。
- 报告列表空态语义对用户可理解。
- 预约/咨询/报告提示文案口径一致，不出现同义不同文案。
- 401 处理一致，不出现页面卡死或循环跳转。
