# Scope Baseline v1

## 1. 基线说明

- 版本日期：2026-03-30
- 来源：`README.md`、`课题简介.md`、`计算机24Z1班243233Y109方颖-开题报告.md` 以及代码静态梳理
- 目标：在不破坏现有 `admin-web/` 可用性的前提下，将管理端能力重构到微信小程序

## 2. 角色与边界

- 用户端（微信小程序）：套餐浏览、预约、报告查询、常识文章、咨询、个人中心
- 管理端（重构目标）：
  - 控制台
  - 套餐管理
  - 分类管理
  - 预约管理
  - 报告管理
  - 用户管理
  - 文章管理
  - 轮播图管理
  - 在线咨询管理
  - 管理员资料
- 后端：`backend/` 统一提供 API，JWT 鉴权，分页与过滤能力

## 3. 本期范围（In Scope）

- 完成小程序管理端 P0/P1 页面与接口联调
- 完成统一请求层（token 注入、401 处理、错误提示）
- 完成接口与字段契约文档，减少联调返工
- 完成主流程测试与演示材料

## 4. 非范围（Out of Scope）

- 支付相关能力
- 第三方医院系统对接（HIS/EMR）
- 大规模数据库重构
- 与课题目标无关的功能扩展

## 5. 当前项目状态（观察）

- `backend/`：Django + DRF 可运行，`/admin/` 可登录
- `admin-web/`：页面路由与基础 CRUD 已具备，可作为重构参照
- `miniprogram/`：用户端页面已存在，具备基础请求封装

## 6. 本周完成标准（Week 1 DoD）

- 完成 `docs/api/api-mapping-v1.md`
- 完成 `docs/api/field-contract-v1.md`
- 确认 P0 页面所需接口无阻断缺口
- 确认权限边界（admin/user）和异常处理策略（401/403/400/500）
